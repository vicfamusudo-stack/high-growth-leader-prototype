# High Growth Leader™ V8

Validation-ready static prototype.

## Files
- `index.html` — customer journey
- `feedback.html` — external reviewer feedback experience

## Public deployment
This is deliberately dependency-free and can be hosted on any static web host. Upload the folder contents and use `index.html` as the entry point. The reviewer page is `/feedback.html`.

Recommended public structure:
- `/` → customer prototype
- `/feedback.html` → reviewer feedback

V8 introduces visible adaptive routing, a first-time assessment, diagnosis, pathway generation, personalised dashboard, evidence portfolio, Step-Away Challenge™, Demo Day and certification.
